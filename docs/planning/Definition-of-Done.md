Definition of Done (DoD) – Fix My Campus

A user story is considered complete when:

All acceptance criteria have been met.

The feature works as expected without known critical bugs.

The code follows the team's agreed coding standards.

Relevant unit and integration tests have been completed.

All automated tests pass successfully.

The feature has been tested against its acceptance criteria.

Any identified issues have been fixed or appropriately addressed.

The code has been reviewed and approved through a GitHub pull request.

The approved changes have been merged into the main branch.

Any relevant documentation has been updated.

The user story has been reviewed and accepted by the Product Owner.

The story's status has been updated in Jira.

Purpose: To ensure that every completed feature meets the team's quality standards and is ready to be included in the application.
